# Assistente Fácil (protótipo Android em Java)

## Como rodar
1. Instale o Android Studio.
2. File > Open > escolha a pasta AssistenteFacil e aguarde o "Gradle Sync".
3. Crie um emulador (Device Manager) ou conecte um celular com depuração USB.
4. Clique em Run (▶).

## Onde mexer depois
- AiService.java: troque ask() pela chamada à sua IA.
- DeviceActions.java: ações reais do telefone (contatos, SMS, SOS...).
- MainActivity.java: as 3 telas (Ajuda, Resultado, Ajustes).

## Virar a tela inicial (launcher)
Aperte o botão Home no aparelho e escolha "Assistente Fácil". Para testar sem risco,
escolha "Só uma vez". Para desfazer: Configurações > Apps > Apps padrão > Tela inicial.
